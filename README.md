# 보험톡 전산

보험팀원용 콘텐츠 제작 사이트. 이 문서에 지금까지 정한 내용과 준비 과정을 모아 둡니다.

## 기능

1. 보험 최적화 블로그 자동화: 주제 입력 → SEO 원고·제목·태그 생성 (네이버 블로그는 글쓰기 API가 없어 붙여넣기는 수동)
2. 인스타그램 뉴스카드 생성: 기사 → 1080×1350 카드 이미지
3. 매일 오전 8시: 고객 발송용 주요뉴스 카드 모음 + 오늘의 보험소식 1가지
4. 인스타그램 릴스 제작 도우미: 대본·자막·썸네일 문구·해시태그

- 다루는 분야: 생명보험, 손해보험, 건강·암·간병, GA 종합
- 뉴스 출처: 보험 전문지, 일반 경제뉴스, 금융당국 보도자료

## 직접 해야 할 일

### 1. OpenAI API 키
1. https://platform.openai.com 가입·로그인
2. Billing에서 결제수단 등록, **월 사용 한도(Usage limit) 설정** 권장
3. API keys → Create new secret key
4. 이 폴더의 `.env.local` 파일 `OPENAI_API_KEY=` 뒤에 붙여넣기

### 2. 네이버 검색 API
1. https://developers.naver.com → Application → 애플리케이션 등록
2. 사용 API: **검색** 선택, 환경: WEB, URL은 나중에 Vercel 주소로 변경
3. Client ID / Client Secret을 `.env.local`에 붙여넣기
- 무료, 하루 25,000회

### 3. Vercel
1. https://vercel.com → **Continue with GitHub**로 가입
2. Claude 앱의 커넥터 카드에서 Vercel 연결

## 주의

- **API 키는 채팅·카톡·메일에 붙여넣지 말 것.** `.env.local`에만 저장합니다. 이 파일은 GitHub에 올라가지 않도록 `.gitignore`에 등록되어 있습니다.
- 이 폴더는 OneDrive 바탕화면이라 클라우드에 동기화됩니다. 키가 노출되었다고 생각되면 즉시 해당 사이트에서 키를 삭제하고 새로 발급하세요.
- 보험 상품을 권유하는 게시물은 협회 광고심의(심의필 번호) 대상일 수 있습니다. 생성 콘텐츠는 정보 전달 위주로 설정합니다.
