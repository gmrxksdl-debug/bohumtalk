# 보험톡 2026-10-21

## 피드 접근 결과
인스타 접근 불가: 웨일 9222 연결 거부. 오늘 실제 팔로잉 피드·릴스를 읽지 못했으며 읽은 게시물/링크는 0개입니다. 아래는 트렌드 관찰 결과가 아니라 보험 상시 소재 기반 대체 기획입니다.

## 후보
1. 청구서류, 진단서부터 발급해야 할까?
2. 실손과 진단비, 청구할 담보 구분하기
3. 보험 설계 전 병력 정리
4. 보험료 갱신 안내서 체크

## 최종 선정
보험금 청구, 진단서부터 떼야 할까요?
병원 방문 전 확인 순서와 질문을 저장해 둘 수 있는 실무 소재입니다.
전일 알릴의무 주제와 겹치지 않으며 확정 지급·절감액을 약속하지 않고 상담 필요성을 연결합니다.

## 사실 확인과 범위
공식 약관의 청구서류 안내를 참고했습니다. 진단서 외 서류의 대체·간소화 가능성이 있으나 특정 회사·상품 안내를 전 보험사 공통으로 확대하지 않습니다. 최신 전체 업계 기준을 확인한 것이 아니며 개별 청구의 필요서류·대체 가능 여부는 [확인 필요]입니다. 청구 결과나 발급비용을 단정하지 않습니다.
- [공식 보험사 문서 1](https://www.samsungfire.com/publication/pdf/ZPB293050_0_20250101_file1.pdf)
- [공식 보험사 문서 2](https://www.idbins.com/cYakgwanDown.do?FilePath=InsProduct%2F%EC%95%BD%EA%B4%80_30547%2831%29_20250401.pdf)

### 1장 MODULE A

### 2장 MODULE D
제목: 서류는 / 청구 내용에 따라 / 달라져요

통원 · 입원 · 수술 · 진단
청구하는 담보와 상황부터 구분해요.
모든 청구에 같은 서류가 필요한 건 아니에요.

구성: 네 가지 청구 구분을 단순 타이포 행으로 정렬. 각 행 옆 작은 플랫 기호. 통계나 금액 없음.

↓

### 4장 MODULE E

구성: 좌우 비교 두 열. 왼쪽 연한 주황, 오른쪽 연한 파랑의 평면영역. 그림자·카드중첩 없음.

### 5장 MODULE F

### 6장 MODULE F
제목: 발급 전 / 이 세 가지만

□ 어떤 담보를 청구하나요?
□ 정확히 어떤 서류가 필요한가요?
□ 대체서류로 가능한가요?

저장해 두고, 병원 가기 전에 확인하세요.

구성: 체크 질문 세 개를 넓은 간격으로 배치. 플랫 파랑 체크 기호, 행 구분선만 허용. 작은 안내문 아래.

### 7장 MODULE G
제목: 필요서류, / 헷갈리나요?

댓글 키워드
서류

청구서류 확인이 어렵다면
댓글로 상담을 요청해 주세요.
진단명 · 주민번호 · 서류 사진은 댓글에 올리지 마세요.

구성: 가장 크게 '서류' 한 단어를 연한 파랑 키워드박스 안에 배치. 댓글키워드 라벨 작게. 개인정보주의 문구 읽히는 크기.
