## 1. 피드·릴스 신호

## 2. 후보
1. 이사 후 보험 주소와 주택 소재지 확인
2. 가족 보험증권 보관 위치 정리
3. 보험 안내 문자·연락처 점검

## 3. 선정과 이유
이사한 뒤, 보험 주소도 확인했나요?
30~40대 가정이 이사 과정에서 놓치기 쉬운 보험 등록 정보를 점검하는 저장형 소재입니다.
직전 실손 중복가입 소재와 겹치지 않고, 불안을 과장하지 않으면서 계약 확인과 상담을 연결합니다.

## 근거와 검증 범위
공식 보험사 모바일 안내의 검색 발췌에서 주택소재지 변경 항목과 홈페이지의 우편물 수령처 변경 항목을 확인했습니다. 상세 페이지 열람은 캐시 실패로 전문을 읽지 못했으므로 현재 전체 보험사의 절차·서류·효력 규칙을 확인한 것으로 확대하지 않습니다. 삼성화재 안내를 타사 공통 자동처리 규칙으로 쓰지 않습니다.
- [삼성화재 모바일 계약관리 안내](https://product.samsungfire.com/m/customer/M_P06_09_05_001.html): 검색 발췌에서 주택소재지 변경 안내 확인. 본문 열람은 캐시 실패.
- [삼성화재 공식 홈페이지](https://www.samsungfire.com/): 검색 결과에서 우편물 수령처 변경 항목 확인.
다른 보험사 PDF는502로 열람하지 못해 근거로 사용하지 않았습니다. 카드의 핵심은 실무 확인 제안입니다. 연락처 변경이 모든 계약에 자동 반영된다거나 반영되지 않는다고 일괄 단정하지 않습니다. 새 주택 보장 가능 여부, 인수조건, 보험료, 변경 절차·서류·시점은 모두 [확인 필요]이며 보험사에 문의하도록 안내합니다. 소재지 미변경이면 무조건 보상 불가 등의 표현은 사용하지 않습니다.
